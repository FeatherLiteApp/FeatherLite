# FeatherLite

A lightweight colour engine for Windows games. Boost colours, fix dull or dark looks, help with
colour-blindness, and tune your PC for the game you're playing - without touching the game itself.

## Download

1. Go to the [latest release](https://github.com/FeatherLiteApp/FeatherLite/releases/latest).
2. Download **FeatherLite.exe** and put it somewhere normal, like your Desktop or Documents folder.
3. Double-click it.

Windows may show a "Windows protected your PC" screen because the app isn't code-signed yet.
Click **More info**, then **Run anyway**.

## Updates

FeatherLite checks this page for new versions when it starts and shows an **Update available** banner.
Click **Update now** and it downloads, verifies and installs the new version for you. You can turn the
check off in Settings. It only asks for the newest version number and sends no personal information.

## How it works

FeatherLite uses the Windows Magnification API (the feature behind the built-in Windows colour filters)
to change how the whole screen is displayed. It never reads, injects into or modifies a game.
